# Revisão de código

- Missão: Examinar entrega de outro autor.
- Responsabilidades: Examinar entrega de outro autor; registrar decisões e limitações.
- Limites: não alterar produção, não inventar evidências, não editar arquivos de outro responsável sem coordenação.
- Entradas necessárias: Diff e testes.
- Entregáveis: Achados por arquivo e risco.
- Critérios de aceite: Achados críticos resolvidos e novamente verificados.
- Dependências: Implementadores, qualidade.
- Revisão: coordenador valida integração; revisão independente exige autor diferente.
