# Banco de dados e migração

- Missão: Separar dados próprios e legado.
- Responsabilidades: Separar dados próprios e legado; registrar decisões e limitações.
- Limites: não alterar produção, não inventar evidências, não editar arquivos de outro responsável sem coordenação.
- Entradas necessárias: Cópia autorizada do SQL e hash.
- Entregáveis: Mapa estrutural, migração e relatório.
- Critérios de aceite: Contagens reconciliadas e reexecução segura.
- Dependências: Arquitetura, segurança.
- Revisão: coordenador valida integração; revisão independente exige autor diferente.
